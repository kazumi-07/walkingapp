🚶 Walking App

【アプリ概要】
散歩履歴を管理するWebアプリケーションです。
ユーザーはログイン後に散歩日、距離、歩数を登録し、 散歩履歴の一覧表示および詳細表示を行うことができます。




【使用技術】

フロントエンド

・React
・JavaScript
・HTML
・CSS

バックエンド
・Spring Boot
・Java

データベース
・H2 Database

バージョン管理
・Git
・GitHub

【機能一覧】

ログイン機能

ログアウト機能

散歩履歴登録機能

散歩履歴一覧表示

散歩履歴詳細表示

入力チェック機能
